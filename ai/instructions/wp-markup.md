# Общие правила:

- Старайся не копипастить классы. Особенно общие.
- Стили можно условно разделить на 2 части. Общие и специфичные для компонента. 
- Общие - это классы для переиспользования(шрифты, контейнер, отступы, сквозное скругление, любые другие повторяющиеся классы на протяжении всей вёрстки)
- Специфичные - как правило стили исключительно под компонент. Они верстаются в BEM (block, element, modifier) стиле   
- Старайся не злоупотреблять вложенностью тэгов. Предпочитай более горизонтальную структуру.

## Пример простой секции:
Вот пример простой секции. Класс container как правило определяет контентную часть сайта.
В specific-class - чаще всего namespace.   
<section class = "container specific-class">
    <img>
    <div class = "specific-class__content-block">
        <h2 class = "title">$title</h2>
        <p>$text</p>
        <button class = "btn">$btnText</button>
    </div>
</section>


# Общие стили:

Всегда если можно предпочитай использование общих стилей. В простой секции Картинка Заголовок Текст - всё можно сверстать с их помощью. 


## Шрифты:
Как правило с ними выделяется пару классов под нужную вариацию и преимущественно используются они. Переопределять в компонентах шрифты - в крайнем случае. 

## container class
Я предпочитаю добавлять его не к общему main тэгу, а к каждой секции. Да это дублирование, но зато когда появляются секции на 100% ширины - у меня меньше проблем с их вёрсткой.

## Вёрстка кнопок:
Как правило для кнопок должны быть свои классы. Для кнопок не задавай ширину явно (кроме случаев, когда макет крайне намекает на фиксированную ширину кнопок), размеры кнопки должны в 95% случаев задаваться свойством padding
Даже несмотря на то, что кнопки в общих стилях, сами по себе

# Вёрстка изображений
Предпочитай для крупных изображений использовать img, а не background. Картинки чаще будут меняться через админку, поэтому 
свойство background используй только для часто повторяющих маленьких элементов в стиле лупы у поиска или стрелок.
Чаще всего у изображений будет класс img-cover.
